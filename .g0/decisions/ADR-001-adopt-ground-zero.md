# ADR-001: Adopt Ground Zero for ChalkTab

- Status: ACCEPTED
- Date / owner: 2026-09-13 / Founder Jelani Brice; recorded by G0-00
- Context and constraints: ChalkTab is the second product under the Founder's G0 AI software-company framework. Product facts must remain in the product repository, while G0 Core stays reusable and free of customer data, credentials, and product-specific assumptions.
- Options and evidence: Continue with ad hoc project documentation; vendor a copy of G0 Core; or pin the private `AgentBim/Codex-Agents` repository and add product-local `.g0` records. G0 Core v1 explicitly recommends the pinned product-local approach when Core is available.
- Recommendation and tradeoffs: Pin Core v1.0.0 commit `3ffccfc6eeec70efcc480443204850ee22bb1312` and keep ChalkTab records under `.g0/`. This adds durable state and gated evidence without duplicating Core; access to the private Core repository remains a dependency.
- Decision / rationale: Adopt the pinned product-local model and assign product ID `G0-P002`, per the Founder's instruction that ChalkTab is G0's second project.
- Consequences, reversibility, and migration implications: Adds documentation and working conventions only. It does not alter runtime code, database schema, customer data, environments, or releases. Reversible by a separately recorded governance decision; historical records should remain available.
- Dissent and resolution: None recorded. Earlier interpretation of G0 as a lifecycle gate was corrected after the Founder supplied the private Core repository.
- Founder gate assessment: Adopting company governance is a significant operating decision. Explicit Founder approval was provided in the Codex task on 2026-09-13. That approval does not extend to production launch, paid services, destructive actions, or major product/architecture/privacy changes.
